# Projetos em Python

Repositório com exercícios e projetos introdutórios de Python.

## Arquivos na raiz

- `desafio_a.py`: exercício de retirada de materiais com validação de quantidade e estoque disponível.
- `detetive_estoque.py`: sistema de estoque com cadastro, listagem, pesquisa, entrada de mercadorias e relatório do valor armazenado.

## Pasta `tarefa/`

Exercícios organizados em pasta:
- `desafio_a.py`: retirada de materiais.
- `detetive_estoque.py`: controle de estoque.

## Pasta `Aula-verdadeira/`

Sistema de gerenciamento de frota de caminhões, com cadastro, listagem, pesquisa, alteração, remoção e estatísticas.

Para executar o sistema de frota, entre na pasta e execute:

```bash
python main.py
```

Para executar o exercício de estoque, execute:

```bash
python detetive_estoque.py
```

É necessário ter o Python 3 instalado.

# Projeto de Estoque em Python

Projeto de estudos com exercícios introdutórios de Python, usando listas, dicionários, funções, condicionais e tratamento de erros com `try/except`.

## Arquivos

- `desafio_a.py`: exercício de retirada de materiais com validação de quantidade e estoque disponível.
- `detetive_estoque.py`: sistema de estoque com cadastro, listagem, pesquisa, entrada de mercadorias e relatório do valor armazenado.

## Como executar

Tenha o Python 3 instalado e execute no terminal:

```bash
python desafio_a.py
```

Para abrir o sistema de estoque:

```bash
python detetive_estoque.py
```
